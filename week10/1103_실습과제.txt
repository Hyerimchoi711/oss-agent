실습 1 -- 좋은 규칙 고르기
1. 코드를 깔끔하게 쓸 것 (△)
'깔끔하게'라는 표현이 모호하여 지켰는지 객관적으로 확인하기 어렵다. 검증 가능한 명확한 표현으로 고쳐 써야 한다.
수정안: PEP 8 스타일 가이드를 준수하고, 함수와 클래스에는 Docstring을 작성할 것
2. 답과 문서는 한국어 개조식으로 쓸 것 ( O )
출력 언어와 형식을 명확히 지정하여 검증 가능하며 필요한 규칙이다.
3. tools.py 와 secret.py 는 고치지 말 것 ( O )
지우면 AI가 파일 수정 실수를 할 수 있다. 지켰는지 쉽게 확인 가능하다.
4. 파이썬 문법을 지킬 것 ( X )
기본적으로 당연히 지키는 사실이다. 코드를 읽거나 린터를 돌려보면 알 수 있는 불필요한 규칙이다. 
5. API 키는 secret.py 에서 불러오고 코드에 직접 적지 말 것 ( O )
보안 실수를 방지하기 위해 필수이다. 코드 리뷰 시 준수 여부를 바로 체크할 수 있다. 
6. week09 에는 tools.py, main.py, README.md 가 있고 tools.py 에는 함수 두 개가 있음 ( X )
규칙이 아니라 단순히 코드를 읽으면 알 수 있는 구조 설명이므로 지워야 한다.
7. 열심히 할 것 ( X )
주관적이며 지켰는지 검증할 수 없는 불필요한 지침이다.
8. (pandas 공식 문서 전체를 붙여 넣음) ( X )
과도한 문서를 전체 수록하는 것은 불필요하다. 또한 지침으로서의 역할에 맞지 않는다.
