# week09 `tools.py` 함수 정리

`tools.py`는 영화진흥위원회(KOBIS) 오픈 API에서 일별 박스오피스 정보를 가져오는 도구 모음이다.

## 공통 설정

- `BASE_URL`: KOBIS 일별 박스오피스 조회 API 주소 (`searchDailyBoxOfficeList.json`)
- `API_KEY`: `secret.py`에서 불러오는 인증 키
- 요청은 `requests.get`으로 보내고, 10초가 지나면 타임아웃된다.

## 함수

### `get_boxoffice_rank_1(date)`

해당 날짜의 박스오피스 1위 영화 제목을 돌려준다.

- 받는 것: `date` (문자열): 8자리 날짜. 예: `"20260824"`
- 돌려주는 것: 1위 영화 제목 (문자열). 예: `"오디세이"`
- 동작: API 응답의 `dailyBoxOfficeList`에서 첫 번째 항목의 `movieNm`을 꺼낸다.

### `get_movie_audience(date, title)`

해당 날짜의 박스오피스에서 특정 영화의 관객 수를 돌려준다.

- 받는 것:
  - `date` (문자열): 8자리 날짜. 예: `"20260824"`
  - `title` (문자열): 영화 제목. 예: `"오디세이"`
- 돌려주는 것: 천 단위 쉼표가 붙은 관객 수 (문자열). 예: `"123,456명"`
- 동작: 순위 목록을 돌면서 제목이 정확히 일치하는 영화의 `audiCnt`를 찾는다.
- 목록에 없을 때: `"'{title}'은 {date} 순위에 없습니다."`를 돌려준다.

## 참고할 점

- docstring의 `data(문자열)`은 실제로는 매개변수 `date`를 가리킨다(오타). 또 1위 함수 설명이 "입력한다"로 되어 있지만 실제로는 제목을 돌려준다.
- 두 함수 모두 API 호출 코드가 똑같이 반복된다.
- 에러 처리가 없다. 네트워크 오류가 나거나, 응답에 키가 없거나, 목록이 비어 있으면(`movies[0]`) 예외가 발생한다.
