# week09 tools.py 함수 정리

## 개요
- 영화진흥위원회(KOBIS) 오픈 API로 일별 박스오피스 정보를 가져오는 도구 모음임
- API 키는 `secret.py`의 `API_KEY`에서 불러옴
- 요청 주소는 `BASE_URL`(일별 박스오피스 목록 JSON)로 고정함

## 함수 목록

### 1. `get_boxoffice_rank_1(date)`
- 역할: 지정 날짜의 박스오피스 1위 영화 제목을 돌려줌
- 입력: `date`(문자열) - 8자리 날짜, 예: `"20260824"`
- 출력: 1위 영화 제목(문자열), 예: `"오디세이"`
- 동작: API 호출 → `dailyBoxOfficeList` 첫 항목의 `movieNm` 반환
- 참고: docstring에 매개변수 이름이 `data`로 오타 나 있음(실제는 `date`), 첫 줄의 "입력한다"도 "가져온다"가 맞음

### 2. `get_movie_audience(date, title)`
- 역할: 지정 날짜 박스오피스에서 특정 영화의 당일 관객 수를 돌려줌
- 입력
  - `date`(문자열) - 8자리 날짜
  - `title`(문자열) - 영화 제목
- 출력: 관객 수 문자열, 예: `"123,456명"`(천 단위 쉼표 포함)
- 동작: API 호출 → 목록을 돌며 제목이 일치하는 영화의 `audiCnt` 반환
- 순위에 없으면 `"'제목'은 날짜 순위에 없습니다."` 문장을 돌려줌

## 공통 특징
- 두 함수 모두 `timeout=10`으로 요청함
- 응답 오류·빈 목록에 대한 예외 처리는 없음
